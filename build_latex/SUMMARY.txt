═══════════════════════════════════════════════════════════════════
   TECHNICAL IMPLEMENTATION
═══════════════════════════════════════════════════════════════════

Conversion Process:
  1. Read all markdown files from guide directory
  2. Parse markdown with regex patterns
  3. Convert to LaTeX equivalents:
     - Math: $...$ and $$...$$ preserved as-is
     - Headers: # → \section, ## → \subsection
     - Bold: **text** → \textbf{text}
     - Italic: *text* → \textit{text}
     - Code: `code` → \texttt{code}
     - Tables: | | → \begin{tabular}
     - Lists: - → \begin{itemize}
     - Quotes: > → \begin{quote}
  4. Add LaTeX preamble with packages
  5. Generate complete document structure
  6. Write to control-electronics-guide.tex
  7. Compile with pdflatex (2 passes for TOC)

LaTeX Packages Used:
  - amsmath, amssymb, amsfonts (math support)
  - hyperref (hyperlinks)
  - listings (code highlighting)
  - geometry (page layout)
  - fancyhdr (headers/footers)
  - comment (excluding mermaid)
